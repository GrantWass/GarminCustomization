# GarminCustomization

Working with my garmin data to create fun visualization

If attempting to run locally:

1. create a config.js file

const config = {
googleApiKey: "YOUR_GOOGLE_MAPS_API_KEY",
name: "YOUR_NAME",
email: "YOUR_EMAIL",
password: "YOUR_PASSWORD",
};
export default config;

2. cd garmin -> npm i -> npm run dev

3. open separate terminal -> python3 heatmap.py
